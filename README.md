# AI HUB — Self-Improving Mobile & Desktop AI Platform

Платформа универсального локального ИИ-ассистента, способного модифицировать собственный исходный код, с поддержкой работы на ПК (терминал) и на Android (полностью автономно).

## 🚀 Особенности
- **Самомодификация:** Агент может изменять файлы интерфейса и логики прямо во время работы через встроенные инструменты.
- **Встроенная локальная модель:** Мобильная версия использует оптимизированный движок `llama.cpp` для запуска моделей семейства Llama-3.2/Qwen2.5 (1B-2B) прямо на процессоре смартфона без интернета.
- **Кроссплатформенность:** Единая кодовая база на Python с интерфейсом на `Flet` (Flutter).

## 📱 Запуск на Android
1. Скачайте собранный `.apk` файл из вкладки **Actions** (или Releases) вашего репозитория.
2. Установите его на телефон.
3. Скачайте любую легкую модель в формате `.gguf` (например, `llama-3.2-1b-instruct.Q4_K_M.gguf` с Hugging Face).
4. Переместите файл модели в память телефона по пути, указанному в приложении (в папку `model/`).
5. Запустите приложение и общайтесь с полноценным ИИ полностью локально!
